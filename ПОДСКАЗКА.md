# Подсказка по камере

## Посмотреть родные режимы камеры

Установите `v4l-utils`, если команды `v4l2-ctl` нет:

```sh
sudo pacman -S v4l-utils
```

Покажите все поддерживаемые камерой разрешения, частоты и форматы пикселей:

```sh
v4l2-ctl --device=/dev/video0 --list-formats-ext
```

Замените `/dev/video0`, если ваша камера находится на другом устройстве. Чтобы узнать текущий формат, используйте:

```sh
v4l2-ctl --device=/dev/video0 --get-fmt-video
```

В параметрах утилиты `--width` и `--height` задают размер **виртуального выхода**. Если он выше выбранного камерой режима, кадр масштабируется. Чтобы выбрать поддерживаемый режим камеры, сначала посмотрите список через `--list-formats-ext`.

## Запуск с цветом

Пересоберите именно release-версию после изменений исходников:

```sh
cargo build --release
./target/release/ascii-virtual-camera --input /dev/video0
```

По умолчанию насыщенность усилена в 3.5 раза, а яркость на 12%. `--saturation 0` делает изображение серым; значение около 4–5 делает красный, синий и оттенки кожи заметнее. Яркость можно настроить параметром `--brightness` от 0.5 до 2. Пример:

```sh
./target/release/ascii-virtual-camera --name "byhinag6shi" --width 458 --height 401 --fps 30 --cell 8 --saturation 4.5 --brightness 1.2
```

Выходная камера передаёт цвет в формате YUYV. Если приложение показывает серое изображение, проверьте, что выбрана виртуальная камера **byhinag6shi**, а не исходная `/dev/video0`, и перезапустите приложение после сборки.
