# ASCII Virtual Camera

Rust-утилита для Linux: захватывает изображение с веб-камеры, преобразует его в цветную ASCII-графику и публикует как отдельную виртуальную камеру V4L2. При запуске сама создаёт устройство через `v4l2loopback`; для системной команды `sudo` запросит пароль.

## Требования

- Linux с V4L2
- Rust и Cargo
- `ffmpeg`
- `v4l2loopback` и утилита `v4l2loopback-ctl` (пакеты обычно называются `v4l2loopback-dkms` и `v4l2loopback-utils`)

На Arch/CachyOS установите утилиту управления loopback-камерами (а если модуль не входит в ядро — также DKMS-пакет):

```sh
sudo pacman -S v4l2loopback-utils
# при необходимости: sudo pacman -S v4l2loopback-dkms linux-cachyos-headers
```

```sh
cargo build --release
./target/release/ascii-virtual-camera
```

Камера появится в списке приложений как **byhinag6shi**. По умолчанию вход — `/dev/video0`, выход выбирается автоматически из свободных `/dev/video10`…`/dev/video63`, размер кадра — 1280×720, частота — 30 FPS. Устройство остаётся в системе после завершения программы; при следующем запуске будет выбрано другое свободное имя `/dev/videoN`.

## Параметры

```text
-i, --input <PATH>    Камера на входе (по умолчанию /dev/video0)
    --output <PATH>   Путь виртуальной камеры; иначе выбирается автоматически
    --name <NAME>     Имя камеры в приложениях (по умолчанию byhinag6shi)
    --width <PIXELS>  Ширина выходного кадра (по умолчанию 1280)
    --height <PIXELS> Высота выходного кадра (по умолчанию 720)
-f, --fps <FPS>      Частота кадров (по умолчанию 30)
    --cell <PIXELS>   Размер ASCII-символа (по умолчанию 8, минимум 8)
    --saturation <N>  Насыщенность от 0 до 5 (по умолчанию 3.5)
    --brightness <N>  Яркость от 0.5 до 2 (по умолчанию 1.12)
    --ramp <CHARS>    Символы от тёмных к светлым
```

Пример с пользовательским именем, камерой и разрешением:

```sh
./target/release/ascii-virtual-camera \
  --input /dev/video0 --name "Моя ASCII камера" \
  --width 1920 --height 1080 --fps 30 --cell 8 --saturation 3.5 --brightness 1.12
```

Например, для разрешения 458×401 укажите `--width 458 --height 401`. Для более ярких красного, синего и оттенков кожи увеличьте `--saturation` (например, до 4.5), а `--brightness` повышайте умеренно (например, до 1.2). Список родных разрешений камеры: `v4l2-ctl --device=/dev/video0 --list-formats-ext` (пакет Arch/CachyOS: `v4l-utils`). Для более детального рисунка уменьшите `--cell`; для более крупных символов увеличьте его. Выходное разрешение выше исходного разрешения камеры будет увеличено масштабированием.
